A completely serverless, hyper-optimized, AI-powered personal Operating System built entirely within a single `.html` file. 

Compass OS bypasses traditional heavy backends by utilizing a **"Bring Your Own Key" (BYOK)** architecture, allowing for infinite scalability with zero hosting costs. All data is cryptographically secured via local browser storage, offering an enterprise-grade, privacy-first user experience.

---

## ⚡ Core Architecture (The Clean Core)

* **Zero-Latency UI:** Built with raw HTML/CSS/JS and Tailwind utilities for instant rendering. No heavy frameworks. No virtual DOM overhead.
* **100% Local Matrix:** Absolute data privacy. The OS does not communicate with external databases. All configurations, tasks, and journals are serialized to the browser's `localStorage` enclave.
* **Hardware Security:** Integrated WebAuthn protocols allow operators to secure the OS matrix using TouchID, FaceID, or Windows Hello.
* **Memory Managed:** Strict `requestAnimationFrame` loops and automatic garbage collection prevent browser memory leaks during extended uptime.

## 🧠 Intelligence Features

* **Multi-Node AI Gateway:** Seamlessly switch between Google Gemini (with live Web Grounding), OpenAI (GPT-4o), or decentralized free nodes. 
* **Autonomous Swarm Agents:** Deploy a 3-node AI swarm (Research, Strategy, Execution) that processes directives simultaneously in isolated asynchronous threads.
* **Holographic Visual Core:** Drag-and-drop image analysis using the floating J.A.R.V.I.S. style orb. 
* **Studio Visualizer:** Integrated DALL-E 3 and Imagen-4.0 hooks for generative image and cinematic sequence rendering.

## 🛠️ Integrated Modules

1. **Dashboard:** Live temporal metrics, universal search (Google, GitHub, Gemini), and daily AI-generated briefings.

## 🚀 Getting Started

Compass OS requires **zero installation**, zero `npm install`, and zero server setup.

1. **Visit the Live Deployment:** [Launch Compass OS](https://nvbs-chikkam.github.io/compass-os/)
2. **Authenticate:** Create a secure PIN or enroll your biometric fingerprint.
3. **Configure:** Open the Settings (`/settings`) to link your premium API keys, adjust the UI glass-blur intensity, and customize your neural background.

### Self-Hosting
Because the entire OS is contained in one file, you can literally download `index.html`, double-click it, and run your OS entirely offline from your local hard drive.
